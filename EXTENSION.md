# Access Browser Extension

A simple browser extension to quickly upload and manage files using Access.

## Installation Guide (For You)

### 1. Download/Navigate to Folder
Make sure you have this `extension` folder on your computer.

### 2. Open Extensions Page
- **Chrome**: Go to `chrome://extensions`
- **Brave**: Go to `brave://extensions`
- **Edge**: Go to `edge://extensions`

### 3. Enable Developer Mode
Toggle the **"Developer mode"** switch in the top right corner.

### 4. Load Unpacked
1. Click the **"Load unpacked"** button (usually top left).
2. Select the `extension` folder from this project directory.

### 5. Reloading
If you make changes to the code, click the reload (circular arrow) icon on the extension card to see updates.

## How to Share with Others

Since this extension is not in the Chrome Web Store, you can share it manually:

### Option A: Send the Files (Developer Mode)
1. Zip the `extension` folder.
2. Send the `.zip` file to your friends/users.
3. Tell them to:
   - Unzip the folder.
   - Go to `chrome://extensions`.
   - Enable **Developer Mode**.
   - Click **Load unpacked** and select the unzipped folder.

### Option B: Publish to Web Store (Official)
To make it installable via a link:
1. Create a developer account at the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/dev/dashboard) ($5 fee).
2. Zip the `extension` folder.
3. Upload the `.zip` to the dashboard, fill in the creative assets (screenshots, description), and submit for review.
